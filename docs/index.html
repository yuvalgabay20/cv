Accessibility statement

This page was built to be usable by everyone, including people who navigate by keyboard, use a screen reader, need larger text, or find movement on screen difficult.

Standard applied

Web Content Accessibility Guidelines (WCAG) 2.2, level AA — the standard published as ISO/IEC 40500 and adopted in Israel as IS 5568.

What is in place

  • Every control is a real button or link, reachable and operable by keyboard alone, with a visible focus indicator.
  • A skip link jumps straight to the main content.
  • Text contrast meets AA in both the light and the dark theme; high contrast mode reaches 21:1.
  • Text scales to 150% without content being lost or overlapping.
  • The system setting for reduced motion is honoured automatically, before anyone touches a control.
  • Nothing flashes, nothing moves on its own in front of text, and no action is on a timer.
  • Adjustable settings for text size, contrast, spacing, font, link emphasis, motion, colour and cursor size.

Known limitations

  • The moving panel behind the page is decoration. It carries no information and is hidden from assistive technology, so a screen reader will not describe it. Turning on "Stop animation" removes it entirely.
  • The PDF version of this CV is a separate document and has not been tested to the same standard. Everything in it is on this page.
  • Layout has been verified down to 375 px wide, which covers current phones. It has not been checked at the 320 px WCAG reflow minimum.
  • The page has been tested by keyboard, at browser zoom, in both themes and with contrast measured. It has not been tested with every screen reader and browser combination in use.

How this was checked

Every text and background pair on the page was measured against the 4.5:1 threshold in both themes; the lowest is 4.6:1. Heading order, landmarks, accessible names, focus order, target sizes and the WCAG text-spacing override were all verified programmatically rather than by eye.

This page collects nothing about you. There is no form, no sign-in and no way for it to send anything anywhere.

No cookies, no tracking

No cookies are set. There is no analytics, no tag manager, no advertising pixel and no third-party script. The page makes no network requests at all once it has loaded — every font, style, script and image is part of the page itself.

What is stored on your device

If you change something in the accessibility panel, that choice is saved in your own browser's local storage so the page remembers it next time. It never leaves your device and it is not readable by anyone else. "Reset all" deletes it.

Because this storage only appears after you have asked for a setting, it is strictly necessary for a function you requested, and no consent banner is required for it.

Hosting

The page is served by GitHub Pages. Like any web host, GitHub processes the technical data needed to deliver a page, which can include your IP address. That happens under GitHub's privacy statement, and I have no access to those logs.

The personal data on this page

The only personal data here is my own, published deliberately so that people I am applying to can reach me. The page is marked noindex, so search engines are asked not to list it.
